Matrix Calculator in C

A console-based Matrix Calculator developed in C that performs various matrix operations such as Addition, Subtraction, Multiplication, Transpose, Determinant, Inverse, Matrix Classification and Export Result.

Features

  • Matrix Addition
  • Matrix Subtraction
  • Matrix Multiplication
  • Transpose
  • Determinant
  • Inverse
  • Identity Matrix Check
  • Symmetric Matrix Check
  • Sparse Matrix Check
  • Export Result to Text File
